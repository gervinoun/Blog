# Blog

A Laravel 13 blog project based on the structure and functionality of the
[teacher's reference project](https://github.com/Kasparsu/ta24ablog).

## Local setup

Requirements: PHP 8.3 or later, Composer, Node.js, and npm.

```bash
composer setup
php artisan serve
```

The initial Laravel setup uses SQLite. Database and authentication changes will
be added in later project stages.
